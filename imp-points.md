## Important Point: Power Operator in JavaScript (`**`)

In JavaScript, we use the **double asterisk (`**`) operator** to raise a number to a power.

### Syntax

```javascript
base ** exponent
```

- `base`: The number we want to raise.
- `exponent`: The power to which we raise the number.

### Example 1: Multiplication vs. Power

```javascript
console.log(5 * 3);  // 15 (Multiplication)
console.log(5 ** 3); // 125 (Power: 5 × 5 × 5)
```

**Remember:**
- `*` means multiplication.
- `**` means exponentiation (raising to a power).
